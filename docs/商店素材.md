# DigiPlayers 商店素材用稿

给 App Store / Google Play 文案与截图用。本文件只约定**定位、字幕与禁忌**；不强制本仓库附带真机图。

**语言**：商店页主语言与应用内学习正文、练习、每日题均为**简体中文**。设置里可切换系统语言；切换后学习内容仍为简体中文（设置页有说明）。

**当前产品能力（截图须一致）**：

- 有：学习路径（继续卡）· 章节阅读 · 练习（拼图 / 哈希 / P2P / 反诈）· 资料与年史 · 隐私政策 / 用户协议 · 删除账号
- 无：广场入口 · 积分兑币 / 提现 · 链上钱包收款

---

## 定位句

**一句话**：DigiPlayers 帮你用短课和练习搞懂区块链基础，并练识别常见骗局。

**副句（可选）**：学完还能按时间线翻资料；学习账号只记进度，不能收款。

不要写成理财工具、交易所或 Web3 钱包。

---

## 商店短描述（建议 ≤80 字）

区块链素养与反诈练习：短课、小游戏和骗局对照，进度跟学习账号走。

## 商店完整描述（可改写，勿改事实）

DigiPlayers 是面向入门者的区块链知识学习应用。

- 跟着路径读短课、做练习（拼图、哈希、节点传消息、反诈识别）
- 资料里按时间线看年史、术语和防骗说明
- 每日一题巩固当天所学（网络不佳时仍会提示，不会整页空白）

学习账号用本机生成的密钥标识，用来同步进度。它**不能收款、不能转账**。应用内可查看隐私政策与用户协议，也可删除账号。

本应用不提供代币发行、积分兑换现金或链上提现。

## 禁止用语

下列词不要出现在商店标题、副标题、描述、截图字幕或宣传图上（除非在**反诈教学内容**里作为「骗局话术示例」，且上下文明确是警示）：

| 类别 | 示例 |
|---|---|
| 钱包 / 资产 | DID 钱包、Web3 钱包、收款地址、充值、链上资产 |
| 金钱激励 | 积分兑币、兑换现金、提现、发 DP、空投奖励、稳赚 |
| 交易产品 | 跟单、内幕、保本理财、交易所下单 |
| 夸大 | 保证学会赚钱、官方发币、投资建议 |

可用替代：

- 「学习账号 / 进度钥匙」代替「钱包」
- 「练习完成 / 进度已记下」代替「积分到账 / 领币」
- 「反诈练习」代替「防骗赚钱课」
